# Apostila interativa de Direito do Trabalho

Abra `public/index.html` no navegador para estudar offline. O arquivo contém o conteúdo, os mapas, os artigos e as questões. Os links para as fontes oficiais abrem com conexão à internet.

## Publicar no Render

1. Envie o conteúdo desta pasta para um repositório Git, com `render.yaml` na raiz.
2. No [painel do Render](https://dashboard.render.com/), selecione **New → Blueprint** e conecte o repositório.
3. Aplique o Blueprint e aguarde o primeiro deploy. Abra o endereço `onrender.com` exibido pelo Render e teste uma questão no celular.

O Blueprint cria um Static Site e publica apenas a pasta `public`. A leitura e os erros ficam armazenados no navegador em que foram registrados. Cada aparelho mantém seu próprio progresso.
